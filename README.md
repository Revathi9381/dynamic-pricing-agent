# Dynamic Pricing AI Agent

## Problem Statement
An AI agent that monitors competitor prices, sales velocity, inventory and demand, and recommends or automatically adjusts product prices or promotions.

## Objective
Set the right price at the right time to help online retailers improve profitability and sales.

## Planned Tech Stack
- Frontend: React + Vite + Tailwind CSS
- Backend: Python + FastAPI
- Database: MongoDB
- Agentic AI: LangGraph
- LLM: Gemini API
- Charts: Recharts
- Version Control: GitHub

## Architecture
Frontend → FastAPI → Agentic AI → Gemini
                    ↓
                 MongoDB
